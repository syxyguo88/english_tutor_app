# Requirements

> **维护规则**：本文件是**项目整体需求**，仅在**人工明确要求**时修改。AI 不得擅自更新。

---

## 1. 项目定位

`[2026-05-15 新增]` **R-2026-05-15-gd-1** — 构建面向**单个家庭**使用的**云端 Web App 原型**，帮助低年级孩子通过**纸质英语绘本**完成「拍照入库 → 家长确认 → 生成练习 → 作答与掌握度 → 复习调度」的闭环。第一版**不是**公开多租户 SaaS，也**不是**原生 iOS App；长期愿景与边界以 `docs/superpowers/specs/2026-05-04-private-english-tutor-app-design.zh.md` 为北星，本文件将其**升格为项目级可验收需求**并与当前仓库实现状态对齐。

---

## 2. 目标用户

`[2026-05-15 新增]` **R-2026-05-15-gd-2** — **家长账号**：管理孩子档案、上传绘本与配套音频、校对 AI/OCR 草稿、确认页面与整书、查看掌握度与复习安排、复核重要或不确定的 AI 判题、维护轻量兴趣标签。  
`[2026-05-15 新增]` **R-2026-05-15-gd-3** — **孩子账号**：完成今日练习与复习、在支持的题型下用键盘或语音转文字作答、获得简洁中英引导与轻量反馈；**不得**管理源内容或掌握度策略。

---

## 3. 核心功能（产品）

### 3.1 绘本与内容管线

`[2026-05-15 新增]` **R-2026-05-15-gd-4** — 支持家长**新建绘本**、按页上传图片（相机/相册）、页面排序/删除/替换；可选上传整本**配套音频**（如 mp3/m4a）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-5** — **家长确认门**：未确认的 OCR 句子、页面、音频对齐、去文字图等**不得**进入正式练习、掌握度统计或复习调度（与领域规则 `confirmedAt`、页面/音频状态枚举一致）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-6** — 每页保留**原图**与**去文字图**两类资产及 OCR 区域/去文字状态；去文字图质量不足时，允许将该页**排除在图片类题型**之外但仍可入库。  
`[2026-05-15 新增]` **R-2026-05-15-gd-7** — 配套音频保存为绘本资产；支持转写草稿与**逐句音频片段索引**；音频用于跟听、家长校对辅助、以及看图说句子的**提示模式**（多句/跨页规则见设计 spec）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-8** — 维护绘本库、句子库、知识项与形态、句子—知识关联；整书确认后生成**初始练习集**并进入复习调度。

### 3.2 练习、掌握度与复习

`[2026-05-15 新增]` **R-2026-05-15-gd-9** — 核心题型包含：**填空**、**看图说句子**、**语法找错**、**用词/短语造句**；练习节奏适合儿童短时完成（目标单次约 5–10 分钟量级，具体题量可随迭代微调）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-10** — 掌握度按粒度 **`孩子 + 知识项 + 形态 + 题型`** 记录；维护掌握分、连续正确、错误标签、下次复习时间等（与领域与持久化模型一致）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-11** — 复习调度采用**固定间隔族**并结合表现调整（同日、D1、D3、D7、D14、D30 及错题缩短间隔等——与 `docs/superpowers/specs/2026-05-04-private-english-tutor-app-design.zh.md` 一致）。

### 3.3 家长端与孩子端体验（当前迭代已落地 / 进行中范围）

`[2026-05-15 新增]` **R-2026-05-15-gd-12** — **家长端**：提供仪表盘入口、绘本列表、上传新绘本、逐书校对确认回路；与 `docs/superpowers/plans/2026-05-12-long-term-roadmap.zh.md` **B 轨**（待校对入口、知识画像、AI 复核队列）对齐的占位或渐进实现。  
`[2026-05-15 新增]` **R-2026-05-15-gd-13** — **孩子端「今日练习」**（`/child/today`）：练习步进、**答对后进入下一题**、会话完成与再练一次；展示近期作答与练习总览（含 P2.3 类总览/打卡条）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-14** — **孩子端「绘本复习」**（C6）：独立路由与导航；按书浏览**已确认句子**的只读/轻交互复习；缩略图在 URL 无效时**优雅降级**（见 `docs/superpowers/specs/2026-05-11-c6-child-book-review-mvp.zh.md`）。

## 4. 工程、协作与仓库形态

`[2026-05-15 新增]` **R-2026-05-15-gd-15** — **两级 Spec**：项目级需求/设计/任务在 `spec/`；**每一处行为变更或新功能**必须通过 `openspec/changes/<name>/` 下单次变更（proposal / design / specs / plan / tasks），归档规则见 `CLAUDE.md`。  
`[2026-05-15 新增]` **R-2026-05-15-gd-16** — **目录目标**：`frontend/` 承载**整棵 Next.js 应用**（含 `src/app`、`public`、前端工具链配置）；`backend/` 承载 **Prisma（schema、migrations、seed）** 以及**未来独立 HTTP API**；根目录保留 monorepo 编排（workspace）、共享 CI、Docker Compose 等——具体树形见 `spec/structure.md`。**从当前「根目录单体」迁往该形态**必须通过**单独一个** OpenSpec 变更（名称建议 `migrate-monorepo-frontend-backend`）跟踪与验收。  
`[2026-05-15 新增]` **R-2026-05-15-gd-17** — **CI**：对约定分支（如 `main`、`mvp-foundation`）在 GitHub Actions 上运行 **Postgres 服务**、**Prisma migrate deploy**、**typecheck / lint / unit tests**，以及 **Chromium Playwright e2e**；合并前保持绿。  
`[2026-05-15 新增]` **R-2026-05-15-gd-18** — **本地开发**：提供可复制的命令序列（Docker 或本地 Postgres、`.env`、migrate、seed、generate、dev/build/test/e2e）；可选 **`RUN_INTEGRATION=1`** 运行 Prisma 集成测试；文档与脚本在目录迁移后须与**新路径**一致。

## 5. 非功能需求

`[2026-05-15 新增]` **R-2026-05-15-gd-19** — **性能**：孩子端关键路径可接受原型级负载；对已知大 JSON 负载有渐进优化项（见 `docs/superpowers/plans/2026-05-10-next-development.md` P3）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-20** — **安全与合规（原型阶段）**：不声称生产级多租户隔离；需记录已知风险（如 DB 内 data URL 体量、缩略图 XSS 白名单待办，见路线图 D5）。  
`[2026-05-15 新增]` **R-2026-05-15-gd-21** — **可观测性**：保留开发期性能剖析环境变量约定（如 `PROFILE_CHILD_TODAY` / `PROFILE_CHILD_TODAY_JSON`），并在 README 或 spec 中可查。

## 6. 数据库与部署约定

`[2026-05-15 新增]` **R-2026-05-15-gd-22** — **数据库**：开发默认 **PostgreSQL 16**（`docker-compose.yml` 与 `.env.example` 对齐）；迁移使用 Prisma Migrate；拉取新代码后约定执行 `prisma migrate deploy`（或等效 npm 脚本）、`db:seed`、`prisma:generate`。  
`[2026-05-15 新增]` **R-2026-05-15-gd-23** — **部署**：当前以**家庭原型**为主；生产形态待定义，需明确与「无对象存储、无真 OCR」原型边界的差异并在 `spec/design.md` 记录。

---

## 7. 非目标（明确不做什么）

`[2026-05-15 新增]` **R-2026-05-15-gd-24** — 第一版**不包含**：公开 SaaS 多家庭、发音/流利度评分、全自动兴趣推断、复杂听力题型体系、以及未经家长确认就把 AI 输出当作正式学习内容。  
`[2026-05-15 新增]` **R-2026-05-15-gd-25** — **原型阶段已知非目标**（与 `docs/superpowers/current-status.md` 一致）：真 OCR/版式理解、对象存储与 CDN、生产级认证与授权、真实 AI 判分与家长复核队列的完整产品化——列入 **E 轨** 待办而非当前验收范围。
