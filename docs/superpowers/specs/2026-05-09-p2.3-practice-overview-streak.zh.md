# P2.3 练习总览与连续打卡（竖切）

日期：2026-05-09

## 目标

在原型中为孩子端提供**可理解的轻量指标**，与 `2026-05-10-next-development.md` 中 **P2.3** 一致：在不大改架构的前提下，展示**连续练习日**与**答题次数**类全局统计，便于后续扩展「星星」等游戏化。

## 范围（本竖切）

1. **连续练习天数（`practiceStreakDays`）**  
   - 基于 `Attempt` 表（或内存仓库中等价记录）的**提交时间**。  
   - 使用**服务器本地时区**的日历日（与 `new Date()` 在 Node 中行为一致，即与运行环境时区一致）。  
   - **若当天尚未作答**：从**昨天**起向前数连续有作答的日历日（孩子白天未练时仍显示昨日累计连续天数）。  
   - **若昨天也无作答**：连续天数为 **0**。

2. **今日作答次数（`attemptsToday`）**  
   - 当前日历日内 `Attempt` 行数（含对错）。

3. **累计作答次数（`attemptsTotal`）**  
   - 该孩子用户下 `Attempt` 总行数。

## 非目标

- 不实现「补签」「冻结」等游戏化规则。  
- 不按知识项展示连续正确（已有 `MasteryStat.consecutiveCorrect` 在域内，本竖切不重复展示）。  
- 家长端总览可后续再接；本竖切以 **`/child/today`** 展示为主。

## 验收

- 孩子端可见三项指标，文案中英可读。  
- `getPracticeRepository().getChildPracticeOverview({ childId, now })`（或等价命名）在 Prisma 与 in-memory 实现行为一致。  
- 对连续天计算有**单元测试**（纯函数 + 或内存仓库集成）。  
- `npm run typecheck` / `lint` / `test` 通过。
